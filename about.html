ABOUT THE PROJECT

Making campus recovery simpler.

A browser-based minor project for Vaishnavi Group of Institutes.

PURPOSE

Why this portal?

Students and staff frequently misplace personal belongings across classrooms, laboratories, libraries, corridors and other campus spaces. A central lost & found portal makes these reports easier to publish, search and resolve.

This project demonstrates how a useful college workflow can be implemented with standard web technologies and browser storage without requiring a server or database installation.

HOW IT WORKS

Four simple steps

  1. ReportSubmit a lost or found item with clear details.
  2. SearchUse keywords, category and status filters.
  3. VerifyCompare identifying information before claiming an item.
  4. ResolveMark a report resolved after successful recovery.
PROJECT MODULES

Core modules

01

Reporting

Validated forms for lost and found items, including optional images.

02

Discovery

Search, category filtering, status filtering and sorting.

03

Management

Dashboard controls for editing, deleting and resolving own reports.

04

Local Data

LocalStorage provides persistent browser-side data without a backend.
